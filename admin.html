महत्त्वाचे: ही सेटअप/प्रोटोटाइप फाइल आहे. Firebase project जोडलेला नाही; त्यामुळे OTP पाठवणे किंवा डेटाबेसमधील चौकश्या दाखवणे सध्या चालू नाही. फक्त HTML लपवून सुरक्षित Admin बनत नाही.

Backend जोडण्याची checklist

  1. Firebase project तयार करा.
  2. Authentication → Phone provider सक्षम करा आणि admin साठी OTP लॉगिन तपासा.
  3. Firestore Database तयार करा.
  4. फक्त अधिकृत admin UID ला चौकश्या वाचण्याची/बदलण्याची परवानगी देणारे Security Rules लावा.
  5. Public form submission साठी server-side validation, rate limiting आणि spam protection जोडा.
  6. OTP आणि database rules तपासल्यावरच Live करा.

फोन नंबर व इतर वैयक्तिक माहिती गोळा करण्यापूर्वी गोपनीयता सूचना द्या आणि आवश्यक तेवढीच माहिती साठवा.
